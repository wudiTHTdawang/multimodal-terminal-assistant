场景 A · 语音 + 视线 + 联系人页面

给他发消息

页面右上角的全局摄像头可在一次授权后被消息、音乐和日程三个模块共用。第一阶段仅展示预览；下一阶段将把画面中的注视方向与当前页面内容对应。当前仍可点击联系人卡片作为备用演示输入。

语音输入：点击下方「🎤 语音输入」，说一句话，浏览器本地识别后交由系统理解执行（文本模拟输入已移除）。

场景 B · 明确场景模式 + 本地音乐偏好

音乐

选择专注、开车或娱乐模式后，系统会从本地模拟音乐平台检索一首适合当前状态的歌曲。推荐会结合当前模式的偏好歌单与该模式下的平台大众常听歌曲，并随你的反馈实时更新。

当前未启用音乐模式。

语音输入：点击「🎤 语音输入」说话即可（如"我喜欢这首""下一首""开始专注"）。

场景 C · 用户授权的本地备忘录

日程安排

可授权多个 `.txt`、`.md` 或 `.json` 备忘录。文件选择窗口中按住 Ctrl 可逐个多选、按住 Shift 可选择连续文件。浏览器不会在后台读取你的文件；文件改动后，请重新选择该文件以更新本地授权副本。

尚未选择授权备忘录文件。

语音输入：点击「🎤 语音输入」说话即可（如"我明天有什么安排""后天有什么安排"）。
