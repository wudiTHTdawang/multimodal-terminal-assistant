Windows 本地演示原型

多模态个性化终端助手

当前为按钮模拟输入。后续将把按钮事件替换为语音识别、视线落点和点头确认模块。

场景 A · 语音 + 视线 + 联系人页面

给他发消息

先点击模拟“注视”的联系人，再输入消息内容，模拟系统根据视线和语音中的“他”完成对象消歧。

场景 B · 明确场景模式 + 本地音乐偏好

音乐

选择专注、开车或娱乐模式后，再通过注视音乐卡片和语音“播放这个”选择音乐。每次播放、喜欢或跳过都会只在当前模式下记录偏好。

当前未启用音乐模式。

场景 C · 用户授权的本地备忘录

日程安排

点击下方按钮后可一次选择多个 `.txt`、`.md` 或 `.json` 备忘录。新选择的文件集会替换旧授权列表，避免遗留文件混入结果。

尚未选择授权备忘录文件。
