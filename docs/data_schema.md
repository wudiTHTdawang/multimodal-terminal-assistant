# 初始数据与交互测试说明

本目录中的所有人物、事项、音乐均为演示数据，不含真实个人信息。全部演示备忘录（`memo_demo.json`、`备忘录演示.txt`、`备忘录演示1.txt`）的日期由 `scripts/refresh_demo_dates.py` 相对运行当天生成（过期示例=昨天，明天=今天+1，后天=今天+2），因此“今天/明天/后天/已过时间”与真实日历一致；服务端 `DEMO_REFERENCE_DATE` 常量随脚本更新，二者始终对齐。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `data/contacts.json` | 联系人页面对象和屏幕坐标 |
| `data/music_library.json` | 本地模拟音乐库及曲风标签 |
| `data/profiles_demo.json` | 两位虚拟用户的可解释偏好 |
| `data/memo_demo.json` | JSON 格式的备忘录结构示例 |
| `data/备忘录演示.txt` | 可在页面中手动选择并授权的 TXT 演示备忘录 |
| `tests/scenarios.json` | 30 条端到端验收样例 |

## 统一事件格式

每个模态事件均须使用同一台电脑的 Unix 毫秒时间戳 `timestamp_ms`。首版不涉及手机与电脑之间的时钟同步。

```json
{
  "timestamp_ms": 1000,
  "modality": "speech_text | gaze | screen_context | head_gesture",
  "value": "事件内容",
  "confidence": 0.95
}
```

## 备忘录权限规则

1. 系统仅在用户通过文件选择器授权后读取指定文件或目录。
2. 初版只支持 `.txt`、`.md`、`.json`；页面通过文件选择器获取用户选中的文件内容，并只在本地保存授权副本。
3. TXT 与 MD 每行使用 `日期 | 时间 | 时长（分钟） | 事项 | 地点 | 优先级 | 详细说明` 的格式；以 `#` 开头的行为说明行。
4. 解析结果和索引只保存在本地；撤销授权时删除对应索引。
5. 生成提醒或改写原始文件属于写操作，必须得到明确语音确认。

## 测试执行原则

- 运行每条样例时，将 `events` 按时间顺序送入系统；
- 比较系统最终的 `expected` 字段，而不是比较自然语言逐字输出；
- `reference_date` 用于处理“明天”等相对日期表达；
- 不可执行、冲突或置信度不足的输入必须返回澄清问题或安全取消，不能默认执行。
