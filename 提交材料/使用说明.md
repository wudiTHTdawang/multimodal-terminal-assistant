# 使用说明

## 1 环境要求

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows 10/11（其他平台可用，界面以 Windows 验证为准） |
| Python | 3.12+（**仅使用标准库，无需 pip 安装任何依赖**） |
| 浏览器 | Chrome / Edge（需支持 Web Speech 与 WebGL，用于语音识别与 MediaPipe 视觉） |
| 摄像头/麦克风 | 发消息页视线选择、手势控制、语音输入需要；无摄像头时可用手动输入替代 |
| Ollama（可选） | 本地大模型解释与语音文本整理：`ollama pull qwen2.5:3b-instruct`，并设置环境变量 `ZHIJI_LLM_MODEL=qwen2.5:3b` |

## 2 快速启动

```bash
# 进入项目目录
cd D:\桌面\人工智能大赛项目

# 启动本地服务
python app.py

# 浏览器打开
# http://localhost:8000
```

页面依次为：发消息 → 音乐 → 日程（顶部可切换）。

## 3 功能操作

### 3.1 发消息（语音 + 视线）
1. 页面右侧为联系人卡片；点击卡片可手动选择对象；
2. 点击“开始录音”（🎤）说出指令，例如“给妈妈发消息，叫他中午回来吃饭”；
3. 识别文本出现在确认框，可编辑后点“确认发送”；点“清空”可重来；
4. 注视联系人时，对应卡片会高亮（黄色框）；系统按“语音姓名 > 手动选择 > 视线 > 历史”确定对象，解释条会显示对象来源；
5. 若视线置信度过低，系统会澄清询问，不会误发；发送前必须确认。

### 3.2 音乐（个性化推荐 + 手势）
1. 顶部切换“专注/开车/娱乐”模式，播放器按模式偏好推荐曲目（每 3 次穿插 1 次大众常听）；
2. 语音“播放下一首”“暂停”“继续”等可直接控制；
3. 竖掌手势 = 暂停/继续（掌心对镜头停留片刻）；
4. 日程页说音乐指令会被忽略（页面级约束，避免误触发）。

### 3.3 日程（查询 + 提醒）
1. 语音“明天有什么安排”“今天有什么安排”“后天呢”等，列表原位刷新显示对应日期事件；
2. 每个事件带“提醒我”按钮，点击后显示“已设置提醒（提前 50 分钟）”；再次点击“取消提醒”可撤销；
3. 支持“设置明天下午组会的提醒”“取消组会的提醒”等语音指令；
4. 已设置提醒的事件再次请求会提示“已设置”，不会重复创建。

## 4 语音识别模式

- 优先使用浏览器 Web Speech（zh-CN，即开即用）；
- 环境变量 `ALLOW_LOCAL_MODELS=true` 时启用本地 Whisper 回退（模型位于 `web/models/whisper-tiny`）；
- 所有识别文本都会进入可编辑确认框，识别错误可现场修正。

## 5 配置项（环境变量）

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `ZHIJI_LLM_MODEL` | 空（禁用 LLM） | Ollama 模型名（≤14B，推荐 `qwen2.5:3b`） |
| `OLLAMA_BASE_URL` | `http://127.0.0.1:11434` | Ollama 服务地址 |
| `ALLOW_LOCAL_MODELS` | `false` | 是否启用本地 Whisper 语音回退 |
| `PORT` | `8000` | 服务端口 |

## 6 演示数据与重置

- 演示联系人/曲库/备忘录为内置样例；备忘录存于 `data/authorized_memos/`（已加入 .gitignore，不随代码发布）；
- 运行 `python scripts/refresh_demo_dates.py` 可将演示备忘录日期重置为相对“今天”的示例（昨天/明天/后天各 1–3 条），并清理过期提醒状态，方便任意日期演示。

## 8 常见问题

- **听不到语音**：检查浏览器麦克风授权；Chrome 需要 https 或 localhost（本项目为 localhost，可直接使用）；
- **视线不生效**：确认摄像头授权且正对镜头；无摄像头时请用手动选择联系人；
- **Ollama 未安装**：不影响核心功能，系统自动使用规则模板应答；
- **端口被占用**：设置 `PORT` 环境变量后重启。
