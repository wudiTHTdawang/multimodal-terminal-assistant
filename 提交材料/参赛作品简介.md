# 参赛作品简介（300 字以内）

本项目面向 AI PC/手机/车载等智能终端，构建端侧多模态感知与个性化应答系统：融合语音、视线、屏幕上下文与手势，对齐理解发消息/音乐/日程意图，以可解释规则基线保障安全，本地大模型（Qwen2.5-3B）负责个性化应答与语音纠错。亮点：①“给妈妈发消息”指代消歧——语音姓名优先、视线辅助、低置信度澄清；②专注/开车/娱乐分场景音乐偏好歌单与手势反馈；③已授权备忘录的日程查询与提醒（可撤销）；④全离线——浏览器端 Whisper 识别、MediaPipe 视觉，音视频不上传，隐私闭环。验收：端到端样例 30/30 通过，单轮应答<5 秒（超时规则兜底）。运行于 Windows 笔记本，无第三方依赖，断网可用。
