# 参赛作品简介（300 字以内）

本项目面向智能终端（AI PC / 手机 / 车载助手），构建端侧多模态输入感知与个性化应答系统：融合语音、视线、屏幕上下文与手势，在时间轴上对齐理解用户意图（消息发送、音乐播放、日程查询），以可解释规则基线保证安全，轻量本地大模型（Qwen2.5-3B，低于赛题 14B 上限）负责个性化应答与语音近音纠错。亮点：①“给妈妈发消息”等指代消歧——语音姓名优先、视线辅助、低置信度澄清；②专注/开车/娱乐分场景音乐偏好歌单，支持点头/摇头/手势反馈；③已授权备忘录的日程查询与提醒（可撤销，支持按钮/语音/视线设置）；④完全离线——浏览器端 Whisper 语音识别、MediaPipe 本地视觉，音频视频不上传，隐私端侧闭环。验收：30 条端到端样例全部通过，单轮应答 <3s（大模型超时由规则兜底）。系统运行于普通 Windows 笔记本，无第三方 Python 依赖、断网可用。
